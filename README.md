# 深度伪造识别标准研究

本目录用于推进《深度伪造识别标准研究》项目材料整理、调研、指标体系设计、benchmark 方案设计、实验验证流程设计和标准草案拟制。

项目核心目标不是单纯设计深度伪造检测模型，而是建立一套“深度伪造视频识别能力评估体系”和“评估标准”。

## 推荐推进顺序

1. 国内外研究现状调研报告。
2. 深度伪造识别能力体系设计。
3. 深度伪造识别能力评价指标字典完善。
4. benchmark 测试方案设计。
5. 指标计算方法和等级阈值校准。
6. 实验验证流程设计。
7. 专家评审材料准备。
8. 深度伪造识别能力评估标准草案。
