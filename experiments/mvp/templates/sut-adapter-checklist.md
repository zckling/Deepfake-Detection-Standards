# 真实 SUT 适配器接入与验收清单

> 本清单用于 E1 真实候选被测对象接入。合成适配器只能验证管线，不得作为真实候选 SUT。

## 1. 身份和复现

- [ ] `system_id` 符合 `SUT-[A-Z0-9-]+`，且在本项目中唯一。
- [ ] 名称、版本、代码修订或镜像摘要已冻结。
- [ ] 模型权重存在时已计算 SHA-256；不存在权重时说明原因。
- [ ] 推理环境、关键依赖、硬件和随机种子已记录。
- [ ] 能力声明只包含真实支持的能力，不因指标要求而虚报。

## 2. 输入边界

- [ ] 明确支持的媒体类型、容器、编解码器、尺寸、时长和语言。
- [ ] 明确批处理与单样本模式，且不会改变样本顺序或身份。
- [ ] 输入不可用、格式不支持和运行失败可区分。
- [ ] 不读取真值、标注、分区用途或其他会造成评测泄漏的字段。
- [ ] 临时文件、缓存和日志的保存及清理规则已说明。

## 3. 输出映射

- [ ] 每个输入恰好产生一条带相同 `sample_id` 的预测记录。
- [ ] `system_id`、`system_version` 和 `run_id` 与运行登记一致。
- [ ] `fake_score` 方向固定为“值越大越可能伪造”，范围为 `[0,1]`。
- [ ] `is_fake_pred` 的阈值来源已记录，且未用 D1/D2/D3 测试真值调参。
- [ ] `processing_time_sec` 的计时边界已固定。
- [ ] 非 `ok` 状态不伪造分数，错误码稳定且可追踪。
- [ ] 只有系统真实输出时才填写 `segments`、`regions`、`evidence_files` 等可选字段。

## 4. E1 验收门

- [ ] 系统登记通过 `system-registry.schema.json`。
- [ ] 全部预测通过 `prediction.schema.json`。
- [ ] 跨文件关系校验无重复、未知引用、漏输出或运行身份错配。
- [ ] D0-SMOKE 运行可在固定环境中重复执行。
- [ ] 运行失败、超时、不支持和缺失输出均保留，不静默删除。
- [ ] 39 项可计算性矩阵已生成，未实现项具有明确原因。
- [ ] 报告明确区分预检、冒烟、正式实验和等级判定。

## 5. 禁止事项

- 不得让适配器读取 `label_state`、标注 payload 或测试集统计量。
- 不得用默认值补齐系统未产生的证据或定位结果。
- 不得把 `unsupported`、`timeout`、`runtime_error` 或 `missing_output` 当作正确预测。
- 不得在未登记的媒体子集上选择性报告结果。
- 不得将 D0 调试结果作为 D1—D3 的独立性能证据。
